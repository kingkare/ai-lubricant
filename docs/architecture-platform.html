业务层 能力层 数据层 技术层 安全治理（贯穿）
部署形态能力层跑在三个进程里：主服务 main.py（:8001→宿主 :3006）、节点控制面 node_server（:8003）、隧道运行时 tunnel_server（仅内网）；同一镜像靠启动命令区分，主服务等另两者健康后才启动。Agent 能力随主服务进程运行，无独立 Agent 进程。

端口

端口归属进程用途
3006主服务Web 入口（容器内 :8001）：门户 /console、管理端 /manager、兼容接口、MCP
8003节点控制面节点连入 + 内部调用，不当网页访问
58160/udp主服务局域网发现广播应答
15432 / 6479PostgreSQL / Redis宿主机调试映射，仅本机
8123 / 9000ClickHouse可选，--profile clickhouse
不对外隧道运行时仅 Compose 内网可达
